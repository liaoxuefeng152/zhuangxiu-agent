# 预估省钱金额功能部署说明（V2.6.1需求）

## 功能概述
在报价单分析报告中添加"预估省钱金额"字段，展示用户通过使用本服务可以节省的金额。

## 修改内容

### 1. 后端修改

#### 1.1 coze_service.py
- 修改了`analyze_quote`函数，在返回结果中添加`estimated_savings`字段
- AI分析结果现在会包含预估省钱金额信息

#### 1.2 models/__init__.py
- 在`Quote`模型中添加了`estimated_savings`字段
- 字段类型：`Float`，用于存储预估省钱金额

#### 1.3 schemas/__init__.py
- 在`QuoteAnalysisResponse` schema中添加了`estimated_savings`字段
- 字段类型：`Optional[float] = None`，确保向后兼容

#### 1.4 api/v1/quotes.py
- 修改了`analyze_quote_background`函数，添加了`estimated_savings`字段的解析逻辑
- 支持从字符串中提取数字（如"约2000元" -> 2000.0）
- 修改了`get_quote_analysis`函数，返回`estimated_savings`字段

### 2. 前端修改

#### 2.1 pages/report-detail/index.tsx
- 在风险评分展示后添加了预估省钱金额展示
- 仅对报价单类型（type === 'quote'）显示
- 仅在分析成功且存在预估省钱金额时显示

#### 2.2 pages/report-detail/index.scss
- 添加了`savings-badge`样式类
- 使用渐变背景和绿色边框，突出显示省钱金额
- 字体大小18px，加粗，居中对齐

### 3. 数据库迁移

#### 3.1 migration_v12_add_estimated_savings.sql
- 为`quotes`表添加`estimated_savings`字段
- 更新现有记录的`estimated_savings`字段（如果`result_json`中有数据）
- 记录迁移历史

## 回滚方案

如果出现问题，可以按以下步骤回滚：

### 1. 回滚数据库
```sql
-- 删除estimated_savings字段
ALTER TABLE quotes DROP COLUMN IF EXISTS estimated_savings;

-- 删除迁移记录
DELETE FROM migration_history WHERE version = 'V12';
```

### 2. 回滚代码
```bash
# 回滚到上一个提交
git revert HEAD

# 或重置到上一个版本
git reset --hard HEAD~1
git push origin dev --force
```

### 3. 重新部署
按照部署步骤重新部署回滚后的代码。

## 注意事项

1. **数据库兼容性**：迁移脚本使用PostgreSQL语法，确保数据库版本兼容
2. **API兼容性**：`estimated_savings`字段为可选字段，确保旧客户端兼容
3. **前端兼容性**：新增的CSS样式不影响现有布局
4. **数据迁移**：迁移脚本会尝试从现有`result_json`中提取`estimated_savings`数据
5. **错误处理**：如果AI分析未返回`estimated_savings`字段，前端不会显示相关区域
